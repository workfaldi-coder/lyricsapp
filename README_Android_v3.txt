SPOTIFY & YOUTUBE OVERLAY FOR ANDROID (v3 — MONOSPACE FONT + 3-LINE LYRICS)
===========================================================================

WHAT'S NEW IN v3:
1. Monospace Font Toggle:
   - Switch between clean Sans-Serif and Monospace (typewriter) font under
     "3. Appearance & Layout". Applies to both the Floating Overlay and
     AMOLED Screensaver (including the clock and track label).
2. 3-Line Lyrics Option (Active Line in Center):
   - Toggle "3-Line Lyrics (Active in Center)" ON to show:
       Line 1 (Top):    Previous lyric line (dimmed, smaller)
       Line 2 (Center): Active lyric line (bold, full color)
       Line 3 (Bottom): Upcoming next lyric line (dimmed, smaller)
   - Works in both the transparent Floating Overlay (automatically resizes
     height to fit 3 lines cleanly) and the AMOLED Screensaver!
   - Toggle OFF anytime to return to single-line mode.

HOW TO UPDATE YOUR GITHUB REPO & BUILD THE v3 APK:
1. Unzip this folder.
2. Open your GitHub repository -> Add file -> Upload files.
3. Drag all extracted files/folders inside the unzipped folder (app, build.gradle,
   settings.gradle, gradle.properties, .github) into GitHub and click Commit changes.
4. Open the Actions tab -> wait ~2 minutes -> download SpotifyYouTubeOverlay-Android-APK
   -> install app-debug.apk right over v2 (all your permissions stay saved!).
